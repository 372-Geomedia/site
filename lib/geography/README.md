# Galveston Bay vector map asset

Primary asset: `galveston-map.json`. Individual SVG paths are under `layers.<name>.path`; `viewBox` is `[0,0,1200,903.42]` (read exact height from JSON). Extent: west -95.02, south 29.24, east -94.70, north 29.45. Geometry uses normalized Web Mercator, with north up. Each layer path is aligned to exactly the same viewBox. Render polygon paths with `fill-rule="evenodd"`.

Layers in recommended paint order: land, wetlands, industrial, water, buildings, waterways, roadsMinor, roadsMajor, coastline. Sea/bay is the background. Roads, coastline and waterways should have fill="none". `land` includes shoreline holes, generated by polygonizing the actual directed OSM coast and extent boundary. Frame edges are included only to close clipped land polygons. Do not stroke land if you do not want extent edges outlined; use the separate coastline path.

`galveston-map-preview.svg` is an optional neutral styled rendering with the same paths, and `galveston-map-preview.png` is a shape QA preview with labels. Use JSON for final interface integration; no styling is required by the data asset.

## Generalization and limits

Coastline and land are simplified by 0.85 normalized display units; other layers use 0.15–0.75 units. Only closed wetland, water and industrial ways are filled: incomplete relation member geometry is never forcibly closed. Buildings are the 340 largest mapped footprints inside the extent, chosen for legibility. This is an editorial map asset rather than a complete database or a navigational map. Shoreline reflects OSM tagging, not a measured current water level. No survey data or measurements are represented.

Place labels and their normalized coordinates are provided. The `illustrativeObservationAnchors` array explicitly contains illustrative placements only; these are not real monitoring stations and should only be used with an illustrative-data label in the interface. Omit them if the interface does not need example markers.

## JavaScript projection helper

```js
function project(lon, lat, map) {
  const rad = Math.PI / 180;
  const merc = phi => Math.log(Math.tan(Math.PI / 4 + phi * rad / 2));
  const {west, south, east, north} = map.extent;
  const scale = map.viewBox[2] / ((east - west) * rad);
  return [(lon - west) * rad * scale, (merc(north) - merc(lat)) * scale];
}
```

Validation: actual coast polygonization yielded 37 faces, 34 classified as land with no unclassified faces. Galveston and Texas City reference points fall on land; known bay and Gulf points fall in water. Bounds and layer alignment were visually inspected in the rendered PNG.
